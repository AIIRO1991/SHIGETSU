# 指月 ―将棋稽古―

一手ごとに評価と解説がつく、ブラウザで遊べる将棋稽古アプリです。無料・登録不要。

## 主な機能（v2.0）
- **CPU研究**：CPUと対局しながら、一手ごとに評価・判定・解説（相手は対局CPU「厳馬」、評価と解説は講師「源庵」。強さは15級〜初段と講師級の10段階）
- **駒落ち**：香落ち〜六枚落ちの7種類（KIFの手合割にも対応）
- **個人研究**：先手・後手とも自分で指して検討（他アプリの棋譜の読み込みにも対応）
- **特定研究**：詰め稽古・受け稽古・大駒狩りを集中練習
- **盤面研究**：好きな局面を作って検討・対局
- **問題研究**：1手詰・3手詰・5手詰・次の一手（各20問、オリジナル）。ヒント付き
- **今日の一問**：日付（例：20261104）から特定研究と同じしくみで作る1問。同じ日ならどの端末でも同じ問題（詰め・受け・大駒狩りを日替わり、起動時に裏で用意）。連続日数つき
- **対面研究**：1台の端末を挟んで2人で指す（盤を大きく表示・向かい合わせ表示・持ち時間）
- **稽古帳**：段級位（15級〜二段、講師級に勝つと三段）・成績・実績16種・定跡図鑑・苦手の分析・卒業証書を自動保存。タイトル画面の「符」で別の端末へ引き継ぎ
- 定跡の案内（代表的な20の定跡）、持ち時間（10分・3分切れ負け／10秒将棋）
- 振り返り（形勢グラフ・勝負所・手筋）、囲い・手筋の図鑑
- 背景画3種（座敷・山河・森）・テーマ6種・盤3種・BGM6曲、日本語／English／中文／한국어／Русский／Français
- **幕間**：起動時やホーム画面から戻ったときに出る入口の画面。タップすると音が鳴る状態になります（座敷は襖、山河は霞、森は朝霧）。タイトルの一番下からいつでも開き直せます
- **眺める**：タイトルのUIを隠して、背景の絵とBGMを楽しむ（画面を押すと戻る）
- **初期化**：設定の「全般」から、稽古帳と設定を消して最初の状態に戻す

## 遊び方
`index.html` をブラウザで開くだけで動きます。設定と稽古帳はブラウザ内にのみ保存されます。

GitHub Pages などの https で公開すると、一度開いたあとは電波がなくても起動できます（`sw.js` が本体とアイコンを端末に保存します）。更新を公開したら、`sw.js` の `CACHE` の名前を変えてください。

旧版（v1.5）は `v1.5/` フォルダに残してあり、`…/v1.5/` で開けます。
