# 指月 ―将棋稽古―

一手ごとに評価と解説がつく、ブラウザで遊べる将棋稽古アプリです。無料・登録不要。

## 主な機能
- **CPU研究**：CPUと対局しながら、一手ごとに評価・判定・解説
- **個人研究**：先手・後手とも自分で指して検討（他アプリの棋譜の読み込みにも対応）
- **特定研究**：詰め稽古・受け稽古・大駒狩りを集中練習
- **盤面研究**：好きな局面を作って検討・対局
- 振り返り（形勢グラフ・勝負所・手筋）、囲い・手筋の図鑑
- テーマ4種・盤3種・BGM4曲、日本語／English／中文／Русский／Français

## 遊び方
`index.html` をブラウザで開くだけで動きます。設定や棋譜はブラウザ内にのみ保存されます。
